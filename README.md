# Расписание недели

Одностраничное расписание на неделю. На широком экране — таблица, на телефоне —
карточки по дням с переключателем и подсветкой текущего дня.

Страница самодостаточна: стили, скрипт и иконка встроены в `index.html`,
внешних запросов нет. Service worker кэширует страницу, поэтому после первого
открытия она работает без интернета.

## Файлы

- `index.html` — страница целиком
- `manifest.webmanifest` — установка на домашний экран
- `sw.js` — офлайн-кэш
- `icon-192.png`, `icon-512.png` — иконки приложения

## Правка расписания

Расписание задано дважды: таблицей в `<table>` (широкий экран) и карточками
в `.days` (телефон). При изменении нужно поправить оба места.
